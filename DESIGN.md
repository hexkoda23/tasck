# TASCK OS Design Notes

TASCK OS uses a restrained operational admin style: dense CRM data, clear stage progression, and low-noise actions. The V1 admin shell should reuse the V3 admin visual language while limiting visible navigation.

- Primary surfaces use warm off-white backgrounds (`#FAFAF7`, `#FBFAF7`) with fine borders (`#E8E4DB`, `#D7CBB8`).
- Primary text is near-black (`#1A1A1A`), muted support text uses grey/brown neutrals (`#8A8A8A`, `#6E6657`, `#4F3E2F`).
- TASCK action green is `#1F4A3A`; amber `#C49B5F` marks Frame/commercial states; red `#B54A37` marks destructive or risk states.
- Headings use Fraunces where existing V3 pages do; numeric/technical labels use JetBrains Mono; body text uses the app sans stack.
- Page sections should remain unframed admin layouts. Cards are for repeated records, focused panels, and modals.
- V1 admin must present real V3 CRM and Business Case workflow data with the simplified V1 nav only.
